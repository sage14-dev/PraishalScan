    PRAISHAL SCAN · PoC build notes. Pipeline: downscale → grayscale/blur → Sobel edge map → Otsu threshold → largest connected region → convex hull → RDP quad → editable corners → perspective warp (homography) → enhance (background-division) → JPEG → PDF (embedded, hand-built writer). Zero dependencies, zero network calls.

    Pass criteria from the validation plan: ≥85% usable auto-detect without corner fixes · warp+enhance <1.5s/page on mid-range phones.

    OCR (the paid hook) is now real: bundled Tesseract.js 7 WASM + eng fast-model, served from this origin (vendor/, tessdata/) — still zero upload. Free tier = 2 searchable pages per document; Pro (unlimited + batch + Word export) is the willingness-to-pay gate.
